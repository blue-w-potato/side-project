# 「其他腳本」元件於儲存腳本時偵測循環引用並阻擋

「其他腳本」元件允許一個腳本呼叫並執行另一個既有腳本,若形成互相呼叫的循環鏈(例如腳本 A 呼叫 B、B 又呼叫 A,或更長鏈),執行時會導致無限遞迴,可能使裝置當機或耗盡資源。決定:於使用者儲存腳本的當下,遍歷該腳本內所有「其他腳本」元件所形成的呼叫圖,偵測是否存在循環引用;若偵測到,阻擋儲存並提示使用者,不允許腳本以含有循環引用的狀態被儲存。

Status: accepted

Considered Options: 不偵測、執行期才發現(使用者手動中止)— 使用者體驗差且有裝置風險,不採用。設定最大遞迴深度自動中止 — 仍允許問題腳本被儲存,只是延後爆發時機,不如提早阻擋直觀,不採用。
