# 元件位置採用相對座標,並於儲存腳本時計算轉換

元件位置(循環點擊位置、拖曳起訖點、按住位置)需要能跨裝置、跨螢幕解析度依然正確重現。決定:使用者在編排畫面上操作的位置,於「儲存腳本」的當下,依照當時裝置的螢幕尺寸換算成相對於螢幕寬高的百分比後才寫入腳本資料;執行腳本時則反向以執行當下裝置的螢幕尺寸還原出實際點擊座標。

由於相對座標是以「寬、高」為基準換算,若腳本建立時記錄的方向(橫式/直式)與執行當下裝置實際方向不一致,寬高會互換,導致座標整個錯位卻不會有明顯錯誤徵兆。因此決定:啟動腳本前偵測裝置目前方向,若與腳本記錄的方向不一致,阻擋啟動並提示使用者切換裝置方向後再執行,而非悄悄地用錯誤座標繼續執行。

Status: accepted

Considered Options: 直接以絕對像素座標儲存 — 實作最簡單,但腳本換裝置或螢幕解析度改變後位置會失準,不採用。執行時不檢查方向、悄悄套用相對座標 — 會在方向不符時產生難以察覺的錯誤點擊位置,風險過高,不採用。
