# 手機自動化腳本系統

一款透過 Android 無障礙服務驅動的自動化腳本執行工具,讓使用者以圖形化介面編排手勢動作序列,依序執行點擊、拖曳、按住等操作。

## Language

**腳本 (Script)**:
一組依序排列的元件,構成使用者定義的自動化行為序列,可被儲存、編輯、啟動執行。
_Avoid_: 巨集, 程序, routine

**元件 (Component)**:
腳本序列中的最小操作單位,共有五種:循環點擊、拖曳、等待、按住、其他腳本。每種元件有固定顏色識別,並可各自設定屬性。
_Avoid_: 動作(除非特指手勢行為本身)

元件顏色對照:
| 元件 | 顏色 |
|---|---|
| 循環點擊 | 黃 |
| 拖曳 | 藍 |
| 等待 | 紅 |
| 按住 | 橘 |
| 其他腳本 | 綠 |

**序列 (Sequence)**:
腳本中元件依執行順序排列的清單,顯示於右側欄,可透過拖曳調整順序。
_Avoid_: 佇列, queue, 清單

**編排畫面 (Editor Screen)**:
使用者新增或編輯腳本時所在的主要工作畫面。依建立腳本時選擇的橫式或直式顯示,背景為全黑(外觀之後再優化),並包含可展開的左側欄與右側欄。
_Avoid_: 畫布, canvas, 編輯器

**左側欄 (Component Panel)**:
編排畫面左側可展開的欄位,顯示所有基本元件圖示與退回鍵,用於將元件新增到序列中。
_Avoid_: 元件庫, 工具列

**右側欄 (Sequence Panel)**:
編排畫面右側可展開的欄位,顯示序列清單(可拖曳排序)與儲存腳本按鈕。
_Avoid_: 大綱欄, 清單欄

**屬性彈出視窗 (Property Popup)**:
點選編排畫面上的元件圖示後彈出的小視窗,用於編輯該元件需要使用者輸入的屬性。透過取消/確定按鈕決定是否套用變更;確定時會先驗證屬性合法性,不合法則拒絕更新並要求修改。
_Avoid_: 設定視窗, inspector

**相對座標 (Relative Coordinate)**:
元件位置以裝置螢幕寬高的百分比表示,而非固定像素值,確保腳本可跨裝置、跨解析度穩定重現。使用者在編排畫面上操作的位置,於儲存腳本時才轉換為相對座標寫入。
_Avoid_: 絕對座標, 像素座標(僅用於對比說明時使用)

**誤差範圍 (Position Jitter Radius)**:
循環點擊、按住等定位型元件,在每次實際執行前,以此範圍內的隨機偏移干擾目標位置後才進行操作,避免每次點擊落在完全相同的像素點。
_Avoid_: 隨機範圍

**懸浮視窗 (Floating Control Window)**:
腳本啟動後顯示在所有應用程式上層的控制面板,提供「顯示/隱藏元件圖示」「執行/中止」「結束」三個功能。同一時間全系統只能有一個懸浮視窗存在(不可同時啟動兩個腳本)。
_Avoid_: 浮動視窗, overlay

**循環引用 (Circular Reference)**:
指「其他腳本」元件形成的腳本互相呼叫鏈(例如腳本 A 呼叫 B、B 又呼叫 A,或更長鏈)。系統於儲存腳本時偵測並阻擋此情況,不允許儲存含有循環引用的腳本。
_Avoid_: 遞迴, 死循環(死循環用於描述執行期行為,循環引用專指資料結構上的呼叫鏈問題)
