# 計畫

# 概述：

這是屬於安卓系統的自訂義腳本系統，為了讓使用者可以讓手機依照一個規律的行為執行動作，跟市面上其他軟體不同之處是，這個程式會有一個執行序列，讓每個元件可以更好的搭配執行。

# 執行時的樣子概述：

1. 這個程式執行後，第一步是訪問權限，取得需要的權限後才會進行下一步
2. 進入到主頁，主頁有以下選項的按鈕：
    1. 已建立的腳本
    2. 新建腳本
3. 點擊新建腳本後，會看到一個畫面，具備兩個按鈕：
    1. 橫式
    2. 直式
4. 無論剛剛選了哪一種，下一步會進入下一個畫面，是供使用者編排元件位置的畫面。根據剛剛的選擇來決定以直式或橫式顯示，不能在編排中切換直式或橫式。
    1. 左邊和右邊都有一個三角形，分別有兩個收起來的欄位，不能同時展開兩個欄位，當其中一個已經開啟時，另一個三角形不能被點擊。
    2. 左邊的三角形點擊之後會展開左側欄，顯示全部的基本元件，以及「退回鍵」。
        
        可以點擊基本元件的圖示，來新增這個元件到這組腳本的序列中，並且有一個圖示出現在供使用者編排元件位置的畫面，可以任意拖曳跟選取。這個元件上面寫的數字代表他在序列中的位置第幾，顏色代表他是哪一種元件。
        
        元件被選取後會有一個小小的彈出視窗，可以修改他的屬性中，需要使用者輸入資料的屬性，即使是同類型的元件，也可以設定不同的屬性。當彈出視窗存在時，不能選取其他元件。當使用者輸入好資料後，可以點擊彈出視窗中的取消或確定，選擇取消時不更新元件的屬性，且關閉彈出視窗；選擇確定時檢查元件的屬性，若有不合規定的，告知使用者，要求修改，拒絕更新屬性，符合規定的話才更新元件的屬性及關閉彈出視窗。
        
        基礎元件中的｢拖曳｣，在左側欄中共用一個圖示，序列中也是屬於一個元件，但是在畫面中是兩個元件。
        
        元件的顏色和屬性規範我額外列出了。
        
    3. 右邊的三角形點擊之後會展開右側欄，會是一個序列，裡面會依序看到所有元件像積木一樣堆疊，透過拖曳這些積木改變順序。
        
        右側欄還有一個很重要的是儲存腳本，點擊之後先跳出一個小視窗詢問是否確定儲存腳本，選擇取消的話關閉小視窗，沒事情發生，如果選擇確定，設定腳本名稱（≥8字元），儲存腳本，關閉剛剛的視窗，發出訊息告知使用者儲存成功。回到程式主頁。
        
5. 到了主頁後，這時候應該有新增一筆紀錄了，即使關閉程式也會存在。
6. 點擊「已建立的腳本」後，這個頁面左上角會有一個返回鍵，可以回到主頁。
    
    如果沒有任何紀錄，中間顯示一排字「尚未建立腳本」
    
    如果有紀錄，由上自下顯示每一筆紀錄的名稱、刪除按鈕、編輯按鈕、啟動按鈕
    
    按下刪除按鈕時，出現一個彈出視窗，確認是否確定刪除紀錄。取消的話關閉彈出視窗，當作沒事發生，確定的話要刪除這筆紀錄，並且更新這個頁面。
    
    按下編輯按鈕時，讀取這筆紀錄，進入供使用者編排元件位置的畫面，以這筆紀錄還原進度，讓使用者可以進行條整。這種情況下在儲存時，設定腳本名稱的位置預設填入舊名稱，方便使用者。
    
    按下啟動按鈕時，出現一個浮動小視窗，顯示在任何程式的上層。他有三個按鍵：顯示/隱藏元件圖示、執行/中止、結束。預設是不顯示元件圖示，顯示/隱藏元件圖示在被點擊後，若元件是顯示的狀態就隱藏，若是隱藏的狀態就顯示在最上層，這些圖示沒有任何互動功能。預設是中止的狀態，按下執行/中止後從頭開始執行這個腳本，如果是執行中的狀態被按下就強行中止，下次執行的時候一樣從頭開始。按下離開時關閉浮動小視窗。
    

# 基本元件列表

## 1. 循環點擊

### 屬性：

- 位置：使用者拖曳圖示
- 誤差範圍 (int, mm, ≥0)：使用者輸入，預設 0
- 間隔時間 (int, ms, >0)：使用者輸入，預設 1000
- 循環次數：選取方格，無限和使用者輸入，預設選取無限
    - 無限：無限循環
    - 使用者輸入：底下多一行讓使用者輸入 (int, >10$^6$)，預設 1

### 敘述：

腳本啟動後，輪到這個元件時，要能在指定位置上，依照間隔時間循環執行點擊的行為，直到完成指定的循環次數。
每次點擊前先將元件的位置透過誤差範圍內的隨機數字干擾，計算出那次點擊的目標位置後再進行點擊。

## 2. 拖曳

有兩個子元件組成，起始位置和終點位置

### 總屬性（無論是選取起始位置或終點位置都能修改）：

- 拖曳花費的時間(int, ms, >0)：使用者輸入，預設 1000

### 起始位置屬性：

- 起始位置：使用者拖曳圖示
- 起始位置誤差距離 (int, mm, ≥0)：使用者輸入，預設 0

### 終點位置屬性：

- 終點位置：使用者拖曳圖示
- 終點位置誤差距離 (int, mm, ≥0)：使用者輸入，預設 0

### 敘述：

腳本啟動後，輪到這個元件時，要從起始位置往終點位置進行等速度拖曳。

## 3. 等待

### 屬性：

- 時長 (int, ms, ≥0)：使用者輸入，預設 1000

### 敘述：

腳本啟動後，輪到這個元件時，什麼都不做，用於輔助其他元件搭配。

## 4. 按住

### 屬性：

- 位置：使用者拖曳圖示
- 時長 (int, ms, ≥0)：使用者輸入，預設 1000

### 敘述：

腳本啟動後，輪到這個元件時，按住指定位置，直到設定的時間到。

## 5. 其他腳本

### 敘述：

這個是最特別的，導入其他紀錄，新增到序列後不會在編排畫面中出現，只有右側欄的序列會出現。

腳本啟動後，輪到這個元件時，執行該紀錄的內容。
